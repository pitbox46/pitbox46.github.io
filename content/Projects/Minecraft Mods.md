Since 2021, I've been creating mods for the popular game [Minecraft](https://www.minecraft.net)
in the Java language.
These mods either add new features or modify preexisting features of the game.

## Public Projects

Here are some of my popular or technically interesting public projects:

- [Item Blacklist](https://github.com/pitbox46/ItemBlacklist):
  Allows server administrators to remove standard methods of obtaining certain items.
- [Horse Combat Controls](https://github.com/pitbox46/HorseCombatControls):
  Adds a new control scheme when riding horses which is more intuitive for some.
- [Hidden Names](https://github.com/pitbox46/HiddenNames):
  Allows customization of player names with built in colors and animations.

## Non-Public Projects

In addition to these projects, I've also done many projects as a hired freelance
developer.
Some of these are listed in my GitHub, but others were handed entirely to the client.
The largest such project was my development on NightmareCraft[^1] for Divine Gaming[^2].
The projects not listed included the following work:

- Optimization of hit scan methods
- Refactoring large systems to be more easily understood
- Collision physics for rotated rectangular prisms in 3 dimensions
- Implementing animations, dialogue, missions, non-player entities
- Bugfixes for my own work and the work of other developers

Some of these projects were done collaboratively, such as my work on NightmareCraft.
